DataMind AI

Autonomous multi-agent analytics platform
Personal Project
Problem — most small businesses need data analysis but can't afford a data science team.
Solution — a pipeline of specialized AI agents — Detective → Analyst → ML Engineer → Guardrails → Reporter — that investigates a dataset, builds models, and writes a full report autonomously.
Challenge — audited the build against a 6-part framework for genuine agentic systems (RAG, Multi-Agent, Guardrails/Eval, LLMOps, Human-in-the-Loop, MCP/A2A) and found real gaps in four of them.
Solved — added lightweight TF-IDF retrieval (avoiding a heavy install that would break free-tier hosting), a guardrails agent that checks the model's own confidence claims for consistency, full per-call latency/token logging, and a human-review gate before flagged results unlock.

FinSight AI

Stock market forecasting platform — MSc capstone
Live
Problem — retail investors get black-box price predictions with no reasoning behind them.
Solution — combines Linear Regression, ARIMA, LSTM and VADER sentiment analysis, with a risk analyzer, a prediction-confidence meter, and a RAG-powered financial assistant.
Challenge — a senior-level code audit surfaced real production risk: a live database committed to a public repo and debug mode hardcoded on.
Solved — removed the exposed database, disabled debug mode, corrected the documentation, then shipped a v3 rebuild with the RAG assistant. Deployed on Google Cloud Run (asia-south1).

CustomerIQ

Customer intelligence: churn, segmentation, CLV
Live
Problem — businesses need to know which customers will leave before they do, and why.
Challenge — the first churn model returned 100% accuracy — not a result, a red flag.
Solved — traced it to data leakage from features correlated with the target, rebuilt the pipeline with proper train/test splits and cross-validation, then benchmarked six models.
Result — Random Forest, 82.26% test accuracy, verified honestly — plus RFM segmentation and CLV estimation.

CreditIQ

Credit risk & loan pre-eligibility system
Live
Problem — loan applicants get rejected with no explanation of why.
Solution — a full decision pipeline — pre-eligibility rules → ML risk scoring → risk banding → plain-English explanation — trained on 265,000+ Lending Club loans (2007–2018).
Result — XGBoost, 0.743 ROC-AUC, 81.2% test accuracy. Every rejection is answered live by a Gemini-powered assistant.
